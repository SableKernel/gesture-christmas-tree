# 🎄 可视化手势圣诞树

用摄像头手势控制的粒子圣诞树 —— 挥挥手，让圣诞树绽放成星云，把照片挂上树梢、托在掌心。

纯原生 HTML / CSS / JavaScript + Canvas 2D，单文件，无需构建，本地运行，画面数据不出浏览器。

## ✨ 效果

- 🎄 粒子圣诞树 + 飘雪 + 金色光晕，白色衬线大字距标题
- 📷 照片墙：点击按钮或直接拖拽图片，照片作为挂饰挂上圣诞树
- 🖐 手势交互（基于 MediaPipe Hands，纯浏览器本地识别）：

| 手势 | 效果 |
| --- | --- |
| 🖐 张开手掌 | 粒子绽放成星云，照片漂浮其中 |
| 👍 竖起大拇指 | 放大手边最近的一张照片 |
| ✊ 握拳 | 收回照片 / 星云回归圣诞树 |
| 🤏 捏合 | 关闭放大的照片 |

- 没有摄像头也没关系，页面按钮可以触发同样的效果

## 🚀 本地运行

纯静态页面，任选一种方式起个本地服务器即可：

```bash
git clone https://github.com/zhaoyanqi/gesture-christmas-tree.git
cd gesture-christmas-tree
python -m http.server 8123
```

然后浏览器打开 <http://localhost:8123>，点击「开启摄像头」并允许权限。

> 隐私说明：摄像头画面仅在你本地浏览器内由 MediaPipe WASM 处理，不会上传任何数据。

## 🛠 技术要点

- Canvas 2D 粒子系统：树形螺旋分布、绽放/回归缓动、雪花与光晕
- MediaPipe Hands（CDN 加载）做 21 个手部关键点检测
- 简单手势状态机：关键点几何特征 → 张开 / 握拳 / 拇指 / 捏合，带去抖

灵感来自抖音 @黑客克星 分享的「圣诞树代码」视频，在其交互思路基础上手写重构，加入了手势识别与照片星云交互。仅供学习交流。
